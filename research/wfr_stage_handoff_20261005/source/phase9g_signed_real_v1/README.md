# Earlier signed-correction and recovered-baseline source

This directory preserves the Python modules of the earlier real-data pilot.
The direct residual and two-branch Hahn--Jordan models are under `pg9learn`;
recovered Practical inference is under `p10recover`. Read `docs/METHOD.md` for
its exact modeling and numerical choices. Source provenance is in `records`.

Historical non-English instructions/notebook and the per-record archived
validation table are not included in this public-oriented handoff. No original
Python module was translated, edited or reconstructed from metric values.
Do not run archive-dependent tests without the authorized external artifacts.
The latest stage uses previously saved baselines rather than retraining them.
