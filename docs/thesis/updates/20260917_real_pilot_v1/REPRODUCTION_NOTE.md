# Reproduction and publication are different operations

No training is needed to publish this V1 source. The supplied clean notebooks are delivery templates with execution disabled until explicitly requested; do not publish your output-rich copies.

Source entry points:
- `research/phase10d_recovered_comparison/notebooks/phase10d_recovered_colab.ipynb`: original baseline recovery/evaluation.
- `research/phase9g_signed_real_v1/notebooks/phase9g_signed_real_colab.ipynb`: agreed real residual task, train/evaluate/compare.

The V1 source has not been revised for the next profile-aware hypothesis. The new update docs describe observations and plans, not an implemented V2.

Keep each package's `RELEASE.json` and source provenance. Do not edit status-at-delivery files or remove duplicated frozen dependencies to tidy the tree. Put current state in this dated update note instead. A reader needs authorized access to the private original checkpoints and matching data to reproduce medical-data results; this public-source bundle does not contain them.
